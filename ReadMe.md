# FinTech Ledger System

## Problem Statement

Design a FinTech Ledger System that manages digital wallet transactions using Data Structures and Algorithms.

---

## Objectives

- Create and manage wallets
- Process transactions efficiently
- Support transaction undo
- Search receipts quickly
- Display wallet analytics
- Demonstrate practical DSA usage

---

## DSA Used

| Feature        | DSA            |
| -------------- | -------------- |
| Wallet Storage | Map            |
| Waiting Room   | Queue          |
| Undo           | Stack          |
| Receipt Finder | Unordered Map  |
| Leaderboard    | Priority Queue |
| Money Web      | Graph          |
| Cheapest Rate  | Dijkstra       |
| Max Approvals  | Greedy         |

---

## Extra Features

1. Wallet Dashboard
2. Transaction History

---

## Time Complexity

| Operation      | Complexity     |
| -------------- | -------------- |
| Wallet Lookup  | O(log n)       |
| Queue Insert   | O(1)           |
| Queue Remove   | O(1)           |
| Stack Push     | O(1)           |
| Stack Pop      | O(1)           |
| Receipt Search | O(1) Average   |
| Dijkstra       | O((V+E) log V) |
| Greedy         | O(n log n)     |

---


## Conclusion

The project successfully demonstrates the application of Maps, Queues, Stacks, Hash Maps, Priority Queues, Graphs, Dijkstra Algorithm, and Greedy Algorithms in a financial transaction system.
